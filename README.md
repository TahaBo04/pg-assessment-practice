# Aptitude Arena — P&G Interactive Assessment Practice

An independent, single-page practice platform inspired by P&G's published interactive assessment descriptions. **Not affiliated with P&G or Aon.** No personality questions, no tracking, no backend.

## Tests

- **Digit:** 6-minute (or 75-second sprint) unique-digit arithmetic equations; order of operations, automatic levels, keypad and live timer.
- **Switch:** 6-minute (or 75-second sprint) colored circle/triangle/square/star permutation puzzles. One to three branches with always exactly one correct answer per level.
- **Grid:** Three 4-minute rounds (or three 60-second sprints), each combining sequential dot memory and mirror / rotation / combination visual distractors.
- **Report:** an unofficial A–E practice grade, numerical scores, memory and visual accuracy, response-time averages and personalized improvement guidance. Local-only personal-best storage.

## Run locally

Open `index.html` in a modern browser. All files are local and use no package manager or API keys.

## Publish with GitHub Pages

1. At <https://github.com/new>, create a **public** repository called `pg-assessment-practice` with an optional README.
2. Upload `index.html` from this project into the repository root (GitHub → **Add file** → **Upload files** → **Commit changes**). If you also upload this README, merge/replace the generated README.
3. Go to **Settings → Pages**. Under **Build and deployment**, set Source to **Deploy from a branch**, Branch **main**, and folder **/(root)**. Click **Save**.
4. Open `https://YOUR-USERNAME.github.io/pg-assessment-practice/` after Pages deployment completes.

P&G's official introduction: <https://www.pgcareers.com/apac/en/interactive-assessments>

Official time windows can change by role or assessment version; questions and grade thresholds are original training approximations, not P&G's proprietary scoring.
